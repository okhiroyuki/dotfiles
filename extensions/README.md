# extensions

dotfiles 管理下に置く、自作のエディタ/ブラウザ拡張機能のソース置き場です。

`tools/` 配下のCLIは「個別にビルドしてグローバルインストール」ですが、こちらはホストアプリ
（VSCode・Chrome）独自の拡張機構でインストールする別の作法のため、`tools/` とは別カテゴリとして
分けています。

`rcup` の symlink 対象外(`rcrc` の `EXCLUDES` に `extensions/*` を指定)のため、ここに置いた拡張は
シンボリックリンクではなく、ホストアプリごとの手順で個別にインストールして使います。更新時も
再インストールが必要です（詳細は各拡張の README を参照）。

ホストアプリごとに配布形式・インストール先が異なるため、`extensions/<host>/<name>/` の2階層で
管理しています。

## VSCode拡張（`vscode/`）

`.vsix` にパッケージ化し、`~/.vscode/extensions/` にインストールします。

| 拡張                                                          | 役割                                                                                  |
| --------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| [`claude-status-vscode`](vscode/claude-status-vscode/README.md) | Claude Codeのセッション情報（コスト・コンテキスト使用率）をVSCodeステータスバーに表示 |

## Chrome拡張（`chrome/`）

`chrome://extensions` の「パッケージ化されていない拡張機能を読み込む」で読み込みます。

| 拡張                                                            | 役割                                                                   |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| [`github-html-viewer`](chrome/github-html-viewer/README.md) | GitHub上のHTMLファイルをレンダリングして別タブで表示するボタンを追加 |

## 新しい拡張を追加する場合

1. `extensions/<host>/<name>/` にソースを配置する（`<host>` は `vscode` / `chrome` など）
2. `extensions/<host>/<name>/README.md` にセットアップ・インストール手順を書く
3. このファイルの該当ホストの拡張一覧に追記する
