## crit レビュー

- `crit` に渡す差分のファイル名は ASCII にする。 `crit` は日本語名のファイルを表示せず、エラーも出さない
- 症状はサマリの件数が変更ファイル数より少なくなることだけである。そのまま承認すると、表示されなかったファイルを見ないまま通すことになる
- `core.quotepath` を無効にしても直らない。環境変数で渡すと `git diff --name-only` の出力は素の UTF-8 になるが、 `crit` 側の表示は変わらない。原因は git のパス表示ではなく `crit` 内部にある
- 既に日本語名で作ってしまった場合は、ベースのコミットごと ASCII 名で組み直し、差分を修正のみに保つ
- レビュー後はサマリの件数と `git diff --name-only | wc -l` を比べる。合わなければ不完全なレビューなので、名前を直して再度回す
