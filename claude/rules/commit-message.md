## 基本ルール（git.md の補完）

- 説明部分は日本語・1行・50文字以内
- 変更内容が一目でわかる形にする
- 「fix」「更新」だけの曖昧なメッセージは不可
  - NG: `fix`
  - OK: `docs: pre-commitルールにyamllint迂回手順を追加`

## プレフィックス（必要に応じて）

`<プレフィックス>: <日本語の説明>` の形式で書く。
使えるプレフィックスの一覧はコミットテンプレート `~/.gitmassage`（リポジトリの `gitmassage`）が正本。
`git commit -m` ではテンプレートが表示されないため、迷ったら `cat ~/.gitmassage` で確認する。
