# Language editor

`japanese-tech-writing` の必須 4 規則に限ってレビューする。事実・解釈・提案・未確認事項の混同、用語の未定義、文書内だけの略語、同じ語の意味の揺れ、参照先を特定できない指示、結果だけでは復元できない因果の欠落、意味が取れない抽象語を指摘する。
文の長さ、表記、空白、読点、です・ます調とである調の揺れ、言い回しが長いことだけでは指摘しない。textlint が検出する指摘も出さない。
意味を変える全面改稿は提案しない。
修正案でも原文にない効果、指標、手順、運用条件を追加しない。根拠が不足する場合は、具体的な数値や運用を補わず、未確認・要確認であることを明示する。
